# 需求映射

自定义函数以两份原始样例为准：准确使用 calculateNumber、sendMsgToXiaoyi，大小写保持一致。PRD 和早期方案中的其他拼写不作为别名启用。协议版本 v0.9，catalog 固定提交 `5c347a8352c1afff31879bcf5af4101df4f94137`。

| 需求 | 实现 | 验收 |
|---|---|---|
| G1 意图适配 | 以 GPT Intelligent UI 体验为目标；根据意图和已获取信息主动组合丰富组件与交互，回复语言遵循上下文 | 独立新题材试用，无需用户点名控件，无组件数量配额 |

| G3 可交互 | 路径初值、函数签名、动态按钮参数、接收方能力 | 初值类型/嵌套函数/动作位置测试；真实端侧联动另验 |
| G4 渐进可用 | 显式语义 regions、依赖闭包、子先父后、完整 root | 首批已有完整区域、逐批校验、最终树一致 |

| 离线依据 | vendor 原文、SOURCE.json 哈希与 Apache-2.0 LICENSE | 运行测试不请求在线协议 |
