# 视觉规则

让用户先看到结论，再找到可以操作的输入。每轮固定一套主题与密度，默认 `light / compact`。布局随任务决定；优先复用[对应组件章节](components/index.md)的模板。确需微调时才查[可用样式字段](style-fields.md)，组件没有的字段不自行补写。

| 角色 | 项目约定 |
|---|---|
| 尺寸 | 字号、宽高、内外边距和圆角等长度写字符串；`"16vp"` 与 `"16"` 都表示 16vp，复合尺寸可写 `"12vp 20vp"`。直接使用设计值，不乘 2 或屏幕密度。百分比和 `auto` 按字段使用。数值 `line-height:1.5` 是倍率；透明度、数量、行数都不加 vp。 |
| 字阶 | 页面标题 30、分组 24、分区 20、小标题 18、正文 16、说明 14、注释 12、短指标 38、按钮文字 16（vp）。标题/指标/按钮可加粗。正文与说明行高常用 1.5，其余角色常用 1.3；每区通常只取标题、正文、说明三级。 |
| 间距 | 用 4/8/12/16/24/32vp。紧凑布局的页面和卡片内边距为 16vp、组间 12vp、区间 16vp；宽松布局分别为 24/16/24vp。 |
| 圆角与触控 | 标签 4、图片 8、卡片 16、按钮 20、宿主弹层 32（vp）。主按钮模板最小高度 48vp；实际点击区域由端侧核验。 |

**默认配色。** 浅色页面 `#F1F3F5`、卡片 `#FFFFFF`；标题 `#16181D`、正文 `#343A40`、说明 `#555D66`，强调 `#0A59F7`。主按钮底色 `#16181D` 配白字。宿主提供深色模板时整套切换：页面 `#111315`、卡片 `#202224`、主字 `#F4F5F6`、正文 `#D5D9DF`、说明 `#AEB6C2`，强调 `#8CB6FF`，主按钮浅底深字。普通文字对实际背景的对比度目标大于 4.5:1。使用六位 HEX；带透明度时按宿主 RGBA 顺序，不照抄 ARGB。

**布局和可读性。** 把输入与它影响的结果放在一起，始终标出数值单位。首个有用区域不要依赖网络图片。一个区域通常只需一层卡片；短标签与数值可以横排，长中文或窄屏优先纵排，不通过缩字或截断藏起日期、价格、条件。图标搭配文字，不能单独承担关键标签。

**组件边界。** 保持模板里的前景/背景配对，按钮字色属于其 Text 子节点。长说明要摘要时，使用 [Text 的摘要模板](components/content.md#text)；富文本按 [RichText](components/content.md#richtext) 自身能力处理。媒体须用真实可用来源，模板中的测试地址不能显示给用户。系统大字体、原生焦点、真实触控区及图片叠层对比度由端侧验收；Web 内页和扩展组件内部主题不由外层样式控制。
