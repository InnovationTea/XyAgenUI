## 2. 明确不做的合并

| 差异 | 处理 |
|---|---|
| HarmonyOS phone 与 PC/watch 字号不同 | 本项目选 phone；其他设备另设 profile |
| 新旧版圆角常用档位不同 | 不把旧 4/8/12/16/24 表说成当前新版同一表 |
| Huawei ARGB / AGenUI RGBA | 转换后使用；优先六位不透明HEX |
| AGenUI Skill 字阶40/36/32/28/24px与Harmony角色不同 | 源表和px单位原样保留；项目采用30/24/20/18/16/14/12/38vp语义字号，属于显式定制 |
| 原始Catalog用px描述且尺寸pattern为可选px | 不改vendor；宿主项目overlay允许vp和原有兼容写法，保留string类型；当前端侧无单位尺寸字符串默认vp |
| 旧视觉包以2倍输出px | 撤销旧2/2候选，默认lengthScale=1/fontScale=1；按逻辑值重新生成，不只替换后缀 |
| 官方Skill强调跨Query不同布局/色彩，用户要统一风格 | 保留自由布局，统一语义主题；明确这是项目选择 |
| 官方Skill的摘要卡骨架与完整交互回复不同 | 摘要卡规则不扩大为全局页面限制 |
| 官方Skill离线结构先行/数据随后，当前项目在线且绑定前初值 | 保留项目在线路径，不照搬工具工作流 |

## 3. 参考资料、旧视觉包与本地有效 Catalog 的具体差异

以下是对实际读取文件的比较，不宣称所有未来版本都一致。例子按照 L01 有效 Catalog 生成。

| 内容 | 参考文档 A03／旧视觉包 | 当前运行基线 L01 | 模板采用 |
|---|---|---|---|
| Web入口 | source 可接URL/HTML | required url | url |
| Table数据 | 示例允许path对象 | columns/rows为字符串数组/二维数组 | 静态数组 |
| Chart图型 | 还写有bar_grouped | line/bar/donut | 三种已定义图型 |
| Button样式 | 某处示例用style | styles | styles |
| Image适配 | 示例写scale-down | 枚举scaleDown | 精确枚举，本包默认cover |
| gap、position等 | 部分说明写不支持 | 本地Schema已列部分属性 | 仅选择所需且已定义的gap等；不扩大到完整CSS |
| 文本样式继承 | 原始目录有闭合继承冲突 | 用户loadCatalog已做精确兼容修正 | 通过同一个有效检查器测试，不宣称原始上游直接通过 |
| Text line-clamp | 旧视觉包以0表示完整文字 | 当前宿主完整文字省略该属性；显式值须为正整数 | 省略0；摘要按需用正整数 |
| RichText line-clamp | 用户旧文字规则曾要求 | 有效Schema不接受 | 不写入该字段 |
| Image/Carousel资源 | 旧视觉包使用res://或Image动态路径 | 当前宿主要求静态、无凭据HTTPS图片直链 | 使用明确标注的example.invalid离线fixture；接入前替换并核验资源 |
