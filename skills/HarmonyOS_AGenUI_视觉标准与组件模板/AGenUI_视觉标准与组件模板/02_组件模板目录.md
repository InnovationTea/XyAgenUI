# AGenUI 组件模板目录与使用契约

**25种目录组件，29个附加样式变体。** 其中22种在用户default profile中开启，Chart、Markdown、Lottie必须单独启用且注册真实实现。模板不是新增的Native组件。

## 0. 三种文件不可混用

| 文件 | 作用 | 能否直接发给渲染器 |
|---|---|---|
| visual-tokens.json | 项目设计参数 | 否，不是官方themeJson |
| templates/*.json | 模型参考；包含元信息、focus、依赖和变体 | 否，不能将templateId等发到A2UI |
| examples/harmony-candidate/*.jsonl | 已展开并补齐依赖的A2UI v0.9消息 | 可作为测试输入；资源、函数、单位和扩展仍需宿主就绪 |

示例统一采用vp逻辑尺寸，默认 lengthScale=1、fontScale=1：正文`"16vp"`，卡片内边距`"16vp 16vp 16vp 16vp"`。用户已确认端侧支持vp、无单位尺寸字符串默认vp；Schema尺寸字段继续用字符串，不能直接改为JSON数值。旧2倍输出已撤销。官方原文px尺度仍仅作来源参考；详情见视觉标准第2节。

固定：所选语义变体的样式。可变：文案、实际资源、数据、组件ID、绑定和被允许的动作。禁止：随意改变字段形态、混入元信息、凭模板名扩展端侧协议。

变体合并方法：非styles字段替换，styles按键覆盖；nodes中的覆盖只应用到指定依赖节点。合并器仅用于离线形成参考示例，不是线上固定页面模板。

下面每个JSON是focus组件片段；有child/children等引用时必须携带模板文件中的dependencies。直接运行请用对应完整JSONL，而不是只复制片段。

## 2. Text

**使用场景：** 标题、正文、说明、关键数值分别选用语义变体。

**交互：** text 可以是字符串、合法路径或返回字符串的函数。

**边界：** Text 样式不复制到 RichText、Button 或 Icon；正文完整换行。数值样式不是自动计算器。

**默认样式片段：**

```json
{
  "id": "focus",
  "component": "Text",
  "text": "先调整预计人数，再按实际食量选择每人用量。",
  "variant": "body",
  "styles": {
    "font-size": "16vp",
    "font-weight": "normal",
    "color": "#343A40",
    "line-height": 1.5,
    "text-align": "left"
  }
}
```

模板：`templates/Text.json`；完整消息：`examples/harmony-candidate/Text.jsonl`。

**可选变体：** `page`, `group`, `section`, `subheading`, `body`, `hint`, `caption`, `metric`, `button`。精确覆盖字段见模板JSON；不要将变体名字写进不支持的A2UI属性。

## 3. Image

**使用场景：** 有信息作用的封面、缩略图或头像。

**交互：** 资源加载与失败表现由 ImageLoader/宿主提供。

**边界：** 显式宽度；不拉伸、不造图；摘要卡不默认大横幅。

**宿主前提：** 以已核验可访问的无凭据HTTPS直链替换example.invalid离线fixture；素材未随包提供；宿主 ImageLoader。

**默认样式片段：**

```json
{
  "id": "focus",
  "component": "Image",
  "url": "https://example.invalid/agenui/template-cover.png",
  "description": "火锅聚餐配图：离线结构fixture，使用前替换为已核验资源",
  "fit": "cover",
  "variant": "mediumFeature",
  "styles": {
    "width": "100%",
    "aspect-ratio": "3/2",
    "border-radius": "8vp"
  }
}
```

模板：`templates/Image.json`；完整消息：`examples/harmony-candidate/Image.jsonl`。

**可选变体：** `thumbnail`, `avatar`。精确覆盖字段见模板JSON；不要将变体名字写进不支持的A2UI属性。

## 4. Icon

**使用场景：** 辅助标题或操作含义。

**交互：** 需要点击时放入真实 Button；图标本身不是业务动作。

**边界：** 只用注册名称；内部颜色跟主题，不写 Text 专属 color；不以单独图标替代关键文字。

**默认样式片段：**

```json
{
  "id": "focus",
  "component": "Icon",
  "name": "shoppingCart",
  "styles": {
    "width": "20vp",
    "height": "20vp"
  }
}
```

模板：`templates/Icon.json`；完整消息：`examples/harmony-candidate/Icon.jsonl`。

## 6. Video

**边界：** 不发明 autoplay、controls、poster 属性；圆角裁剪及比例需端侧测试。

**宿主前提：** 提供 res://template_video；资源未随包提供；媒体解码与权限。

## 8. Row

**使用场景：** 短标签与值、图标与标题、短操作组。

**交互：** 展示子节点的变化，不替代数据计算。

**边界：** 长标签改纵向；不通过缩小字号强行一行；禁止价格和单位异常拆行。

## 11. List

**使用场景：** 同类信息重复、每项独立采购状态。

**交互：** 模板内部使用相对路径；每个条目独立写回。

**边界：** 输入列表的后续结构更新不可重置已勾选状态；不承诺拖拽、侧滑、分页。

## 14. Button

**使用场景：** 主操作、次操作、文字操作；同一区域建议最多一个主操作。

**交互：** 本例调用你宿主已声明的 sendMsgToXiaoyi；点击时执行。

**边界：** 动作是项目宿主扩展，不冒充官方内置；不可把颜色写到 Button 当文字色；禁用/加载态交给实际支持接口。

**宿主前提：** 宿主注册 sendMsgToXiaoyi；按当前契约执行；样式按48vp目标输出；真实触控区域仍需端侧量测。

```json
      },
      "returnType": "void"
    }
  },
  "styles": {
    "min-height": "48vp",
    "padding": "12vp 20vp 12vp 20vp",
    "border-radius": "20vp",
    "align-self": "center",
    "background-color": "#16181D"
  }
}
```

模板：`templates/Button.json`；完整消息：`examples/harmony-candidate/Button.jsonl`。

必须一起发送的依赖节点：`button_label`。

**可选变体：** `secondary`, `text`。精确覆盖字段见模板JSON；不要将变体名字写进不支持的A2UI属性。

```json
    {
      "label": "🍲 清淡锅底",
      "value": "mild"
```

## 27. 五类组合规范

| 组合 | 结构 | 固定项 | 保持动态 |
|---|---|---|---|
| 标题说明 | Column(Text.section, Text.hint) | 字阶、8–12vp间距 | 标题与内容 |
| 参数结果 | Card(Column(输入控件, 说明, 指标)) | 单层外壳、稳定结果位置 | 输入路径与计算关系 |
| 标签数值 | Row(Text.body, Text.metric/section) | 对齐、单位不拆散 | 数值绑定 |
| 选择行动 | ChoicePicker + Button + Text标签 | 选项区与CTA分行 | string[]选择和点击时快照 |
| 列表采购 | List模板(Column(名称, 数量, CheckBox)) | 重复项结构一致 | 每项状态、数量 |

完整联调例子 `examples/hotpot_composition.ndjson`：两区域在线追加；3人确定，Slider调每人克数，calculateNumber与formatNumber输出合计；第二区域增加口味选择和sendMsgToXiaoyi。算式和动作属于用户宿主能力，不冒充官方内置算术或发送函数。仅作联调数据，不是饮食建议。

## 28. 每类控件的状态验收

| 对象 | 最低验收 | 不要伪造 |
|---|---|---|
| Button | normal、pressed、focus、执行反馈、重复点击处理 | 未开放的loading/disabled字段、生成时已发送 |
| 输入 | 空、合法、非法、中间编辑状态、键盘 | 数字外观等于number；只在显示层取整 |
| 选择 | 初值、selected、键盘/触控、string[] | 稳定value随emoji变化 |
| Modal/Tabs | 打开/关闭/切换、焦点和内容完整 | 新的openModal或selectedIndex字段 |
| 媒体 | 加载中/失败/成功、控件可触达 | 资源未提供却声称已展示 |
| 富文本/图表 | 内部层级/颜色/字号、长内容 | 一个外围styles能控制全部内部子节点 |

所有状态最终是否可通过JSON控制，以目标Catalog和宿主实现为准；设计验收项不是自动新增的协议字段。
